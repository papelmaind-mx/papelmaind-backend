# 📌 Capa BuJo (Bullet Journal Técnico)

Esta carpeta contiene **Notas (NXX)** estables, versionadas e indexadas que capturan decisiones de arquitectura, conceptos y diseños.
A diferencia del `dev-log` (efímero) o los `runbooks` (procedurales), estas notas responden al **"por qué"** y sobreviven a largo plazo.

> **Regla de oro:** El índice (`INDEX.md`) se regenera automáticamente con el skill `bujo-note: reindex`. No lo edites manualmente.
